===================
Gate-Model Workflow
===================

You describe your gate-model circuits using the :ref:`index_gate` package's
quantum circuit description language (QCDL), introduced in the
:ref:`gate_workflow` section and described in detail in the :ref:`gate_api_ref`
section. You can then submit your QCDL program to a gate-model solver, for
example a dual-rail simulator, as described in the :ref:`qcdl_using_simulator`
section.
